# SKL 坐标助手

一个面向 `https://skl.hdu.edu.cn/` 的 Chrome Manifest V3 扩展。它管理预登记的 WGS-84（EPSG:4326）坐标，并在目标页面调用 Web Geolocation API 时返回当前选中的坐标。

当前版本只负责坐标配置与页面定位接口适配，不接管登录、签到码输入，也不处理或绕过阿里云验证码。

## 本地安装

1. 打开 `chrome://extensions/`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本仓库根目录。
5. 点击扩展图标，登记 WGS-84 纬度、经度并启用。
6. 重新加载 SKL 签到页面。

## 开发

项目没有运行时第三方依赖，可直接加载源码目录。Node.js 仅用于静态检查和测试：

```bash
npm run verify
```

## 工作方式

- `src/main-world.js` 在页面脚本运行前安装 Geolocation 适配层。
- `src/content.js` 从 `chrome.storage.local` 读取设置，并桥接到页面主执行环境。
- `popup/` 提供位置的新增、删除、切换和启停界面。
- 未启用或没有有效坐标时，调用会回退到浏览器原生定位。
- 权限和脚本注入范围仅限 `https://skl.hdu.edu.cn/*`。

## 数据与使用边界

坐标仅保存在本机 Chrome 扩展存储中，不会由扩展主动上传到其他服务。请只在你有权使用的账户、地点和测试场景中使用，并遵守学校规定及适用规则。
